# 📚 SiJAB - Sistem Jadwal Pembelajaran Anti-Bentrok

![Version](https://img.shields.io/badge/version-2.0-blue)
![License](https://img.shields.io/badge/license-MIT-green)

**SiJAB** adalah aplikasi web sederhana namun lengkap untuk mengelola jadwal pembelajaran di sekolah dengan sistem validasi anti-bentrok 3 lapis.

## ✨ Fitur Utama

- ✅ **Validasi Anti-Bentrok 3 Lapis**: Guru, Kelas, dan Ruangan
- 📊 **Dashboard Statistik** real-time
- 🗂️ **Data Master**: Guru, Kelas, Mata Pelajaran, Ruangan
- 👁️ **Multi-View Jadwal**: Per Kelas / Per Guru / Per Ruangan
- 📅 **Matriks Jadwal** mingguan berwarna
- 💾 **Auto-save** ke LocalStorage
- 📥 **Export/Import** data (JSON backup)
- 🖨️ **Cetak PDF** untuk panduan guru & kelas
- 📱 **Responsive** untuk mobile & desktop

## 🚀 Cara Menggunakan

### Online (GitHub Pages)
Akses langsung: `https://username-anda.github.io/jadwal-anti-bentrok/`

### Lokal
1. Clone repository ini
2. Buka file `index.html` di browser
3. Mulai input data!

## 📖 Dokumentasi

- 📘 **Pegangan Guru**: `panduan-guru.html` → Print sebagai PDF
- 📗 **Pegangan Kelas**: `panduan-kelas.html` → Print sebagai PDF

## 🛠️ Teknologi

- HTML5 + CSS3 (Modern Design)
- Vanilla JavaScript (No Framework)
- LocalStorage untuk persistensi data
- Print CSS untuk export PDF
